## What the next tickets must fit around (from T08, not obvious from the spec)

- **`app/content.py` owns Pages and Tournament items.** Every function takes the acting user and refuses anyone
  without the new capability `manage_pages`. Both route modules (`app/routes/pages.py`, `app/routes/tournaments.py`)
  sit behind `requires("manage_pages")`.
- **Shared helpers moved this session.** Use them rather than writing new ones:
  - `web.form_text` and `web.id_or_none`: the latter rejects non-ASCII digits and ids above SQLite's maximum;
    the Guide routes use both now;
  - `guides.SLUG`: the slug pattern for Guides and Pages;
  - `rendering.preview_warnings`: the labelled 游戏术语检查 list for any preview;
  - `admin/content_preview.html` with `routes.pages.preview_page`: the preview for anything matching the
    `content.TextBearing` protocol.
- **The dashboard count** (`publish.changes_not_on_site`) adds `content.changes_since`:
  - Each Page and Tournament row has `site_changed_at`, set on Publish, on an edit while Published, and on
    Unpublish.
  - Items deleted after they were ever Published go into `removed_content`.
  - When an announcement changes on the site, its Published recaps are marked changed too
    (`_recaps_change_with`).
  - A new change that alters what the site shows must set `site_changed_at` the same way.
- **Site build** (`app/publish.py`):
  - `_Writer` gets `nav_pages` and works out each tree's navigation once.
  - New `LABELS` keys: `guides`, `tournaments`, `announcement`, `recap`, `tournament_date`,
    `no_tournament_items`, `follows`.
  - A Chinese-only Page's language switch falls back to `en/#no-english-text`, a Chinese-only Tournament item's to
    `en/tournaments/#no-english-text`. Both pages carry the `.fallback-notice` paragraph.
  - **A new top-level folder in a language tree must be added to `content.RESERVED_SLUGS`,** or
    `test_every_folder_the_site_build_makes_is_a_slug_no_page_can_take` fails. That is on purpose: otherwise a
    Page slug could overwrite the folder.
- **Tournament item ids are AUTOINCREMENT**, because the public address is `tournaments/<id>/`.
- **`_trimmed` (PEP 695 generic syntax)** is fine: `pyproject.toml` requires Python ≥ 3.12.
