## What the next tickets must fit around (from T07, not obvious from the spec)

- **One render function:** `rendering.render_markdown(text, lang, glossary)` returns `Rendered(html, warnings)`.
  - Every Markdown body goes through it: the preview, the review page, the Review-note quote check
    (`guides._checked_notes`) and the Site build (`publish.environment(glossary)`, filter `markdown(lang)`).
  - Get the glossary with `game.glossary(conn)`.
  - **T08's Pages and Tournament items** should render their bodies the same way, so markers work there too. That
    means the Jinja filter `|markdown(lang)` on the site and `render_markdown(..., lang, game.glossary(conn))` in
    the console.
  - Titles are plain text, never rendered. `rendering.title_warnings` covers them in the preview.
- **nh3 keeps only `class="term"` on `<span>`** (`allowed_classes`). A new class in sanitized HTML has to be added
  there.
- **Markers in markdown-it:** the inline rule `_game_term` returns False in silent mode on purpose, so a marker
  inside a link label doesn't cancel the link. `_Renderer.renderInlineAsText` puts the term's name into image alt
  text.
- **Game Terms:**
  - Heroes are managed on `/admin/heroes`, the other six kinds on `/admin/terms`, and CSV import is at
    `/admin/terms/import`.
  - No two terms of one kind share an English Official name (ignoring case). Different kinds may.
  - Nicknames are stored one per line in `game_terms.nicknames` (added via `ADDED_COLUMNS`). Write them through
    `game._to_store`.
  - `game.nickname_notices` flags one-character Chinese nicknames. Routes flash these with the new flash kind
    `notice` (`.flash-notice` in `base.html`).
- **Route order in `app/routes/game.py`:** `POST /admin/terms/import` must stay declared before
  `POST /admin/terms/{term_id}`, which would otherwise catch it (there is a comment).
- **Seed:** `scripts/seed_demo.py` imports `scripts/demo_game_terms.csv` with `only_new=True`, so re-seeding never
  overwrites an Admin's edits. The user checked the demo Item names on bazaardb.gg. T08 adds the demo Page and
  Tournament items, as the seed docstring says.
- **Wide console tables:**
  - Wrap them in `<div class="scroll">`.
  - A cell holding a sentence can take `class="wrap"`, which lets it wrap inside the scrolling table, as the CSV
    rejection reasons do.
